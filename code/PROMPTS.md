# Prompts

Every prompt below is the complete user message of one query; nothing precedes it except, where one is set, the one-line system prompt `Answer the question.`. The examples are generated by `scripts/make_prompts_md.py`, with the default base seed, from the same functions that the run scripts use (`particle_agents/ising.py`, `roles.py`, `lanes.py`). What changes from query to query is stated for each prompt; the fixed sentences never change.

## 1. Ising single particle

### 1.1 Tests with letters

The two states are shown as A and B. In the randomized queries the program draws for every query which letter denotes +1 and the order of the four neighbours; in the identical prompts both are fixed. Four versions differ only in the rule line.

**Scoring rule stated** (`rule`; example `rule|+1|3|0`: own state +1, three neighbours +1, B = +1)

```text
There are five people here, each in one of two states, A or B.
Last time your state was: B
Last time the other four were in:
First: B
Second: A
Third: B
Fourth: B
Scoring rule: among the other four, for each one whose state is the same as the state you choose now, you gain 1 point; for each one that differs, you lose 1 point. Please choose the state that gives you the highest score.
Now please choose your state again.
No need to explain. On the last line write only "Answer:" followed by A or B, nothing else.
```

**No rule sentence** (`norule`; example `norule|-1|1|0`: own state -1, one neighbour +1, B = +1)

```text
There are five people here, each in one of two states, A or B.
Last time your state was: A
Last time the other four were in:
First: A
Second: A
Third: B
Fourth: A
Now please choose your state again.
No need to explain. On the last line write only "Answer:" followed by A or B, nothing else.
```

**Rule and "if equal, switch"** (`switch_tie`; example `switch_tie|+1|2|0`: tie, A = +1). The added sentence follows the rule on the same line.

```text
There are five people here, each in one of two states, A or B.
Last time your state was: A
Last time the other four were in:
First: B
Second: A
Third: B
Fourth: A
Scoring rule: among the other four, for each one whose state is the same as the state you choose now, you gain 1 point; for each one that differs, you lose 1 point. Please choose the state that gives you the highest score. If both choices give the same score, switch to the state different from your last one.
Now please choose your state again.
No need to explain. On the last line write only "Answer:" followed by A or B, nothing else.
```

**Rule and "if equal, choose one at random"** (`random_tie`; example `random_tie|-1|2|0`: tie, A = +1)

```text
There are five people here, each in one of two states, A or B.
Last time your state was: B
Last time the other four were in:
First: B
Second: A
Third: B
Fourth: A
Scoring rule: among the other four, for each one whose state is the same as the state you choose now, you gain 1 point; for each one that differs, you lose 1 point. Please choose the state that gives you the highest score. If both choices give the same score, choose one at random.
Now please choose your state again.
No need to explain. On the last line write only "Answer:" followed by A or B, nothing else.
```

### 1.2 Temperature tests

Spins are shown as +1 and -1, neighbours in state +1 are listed first, and the queries of a cell are identical. The test with the tool uses the same prompt; the prompt does not mention the tool.

Example `temperature|T2.27|+1|3|0`: T = 2.27, own spin +1, three neighbours +1.

```text
You are one site of a two-dimensional Ising model with coupling J = 1 and no external field. The system is at temperature T = 2.27 (in units of J/k_B) and evolves by heat-bath (Glauber) dynamics.
Your current spin is: +1
Your four nearest neighbours' spins are: +1, +1, +1, -1
Perform one update of your spin according to the dynamics at this temperature.
No need to explain. On the last line write only "Answer:" followed by +1 or -1, nothing else.
```

**Tool offered in the test `temperature_tool`**

- name: `random_uniform`
- description: "Returns a random real number drawn uniformly from the interval [0, 1)."
- parameters (JSON schema):

```json
{
  "type": "object",
  "properties": {},
  "required": []
}
```

- reply to the model: the number, rounded to four decimals, as text (e.g. `0.0895`)

## 2. Three-role problem

In every query the program assigns the letters A, B, C to the three roles (six assignments) and shuffles the order of the six teammates. The examples show the local optimum (teammates 3-2-1, own role on the 1) unless stated otherwise.

### 2.1 Goal and die (condition `0`; example `0|14|0`)

```text
You are one member of a team. Each member takes one of three roles: A, B or C.
Your role right now is: C
You work directly with six teammates. Their roles right now are:
First: B
Second: B
Third: A
Fourth: C
Fifth: B
Sixth: A
Rule: each teammate who has the same role as you counts as one conflict. The team's goal is that nobody has any conflict.
Each member sees only their own six teammates.
A tool named draw is available: given a weight for each of A, B and C, it returns one role drawn at random with probability proportional to the weights. You may use it or not.
Now choose your role.
No need to explain. End your final reply with a line that contains only "Answer:" followed by A, B or C.
```

**Tool offered with every goal-and-die prompt**

- name: `draw`
- description: "Draws one of the roles A, B, C at random. The probability of each role is its weight divided by the sum of the three weights, so a larger weight makes that role more likely and a weight of 0 means it is never drawn. Weights must be non-negative and at least one must be positive. Returns the role drawn."
- parameters (JSON schema):

```json
{
  "type": "object",
  "properties": {
    "weight_A": {
      "type": "number",
      "minimum": 0,
      "description": "Weight for role A"
    },
    "weight_B": {
      "type": "number",
      "minimum": 0,
      "description": "Weight for role B"
    },
    "weight_C": {
      "type": "number",
      "minimum": 0,
      "description": "Weight for role C"
    }
  },
  "required": [
    "weight_A",
    "weight_B",
    "weight_C"
  ],
  "additionalProperties": false
}
```

- reply to the model: `Role drawn: X` with X the letter drawn, or `Error: give three non-negative numbers, not all zero. No role was drawn.`

### 2.2 Added sentences (conditions H, F, I, S and their combinations)

The sentences are added to the goal-and-die prompt, always in this place and order:

- **H** (hint), appended to the line "Each member sees only their own six teammates.": "It is known that if every member always takes the role that gives them the fewest conflicts, the team can end up with conflicts that never go away."
- **S** (order of updates), a line of its own: "Members choose in turn, not all at the same time: your teammates' roles will not change while you choose."
- **F** (facts about the whole team), a line of its own: "The whole team is much larger than the seven of you, each member has a different set of six teammates, and an assignment of roles in which nobody has any conflict exists."
- **I** (instruction), a line of its own: "To get the team out of such a stuck state, a member who has a conflict sometimes has to take a role that is not the best for them at that moment."

Example with all four (condition `HSFI`; `HSFI|14|0`):

```text
You are one member of a team. Each member takes one of three roles: A, B or C.
Your role right now is: C
You work directly with six teammates. Their roles right now are:
First: B
Second: B
Third: B
Fourth: A
Fifth: C
Sixth: A
Rule: each teammate who has the same role as you counts as one conflict. The team's goal is that nobody has any conflict.
Each member sees only their own six teammates. It is known that if every member always takes the role that gives them the fewest conflicts, the team can end up with conflicts that never go away.
Members choose in turn, not all at the same time: your teammates' roles will not change while you choose.
The whole team is much larger than the seven of you, each member has a different set of six teammates, and an assignment of roles in which nobody has any conflict exists.
To get the team out of such a stuck state, a member who has a conflict sometimes has to take a role that is not the best for them at that moment.
A tool named draw is available: given a weight for each of A, B and C, it returns one role drawn at random with probability proportional to the weights. You may use it or not.
Now choose your role.
No need to explain. End your final reply with a line that contains only "Answer:" followed by A, B or C.
```

### 2.5 Prescribed rules

No goal and no tool. The random number in the heat-bath prompts is drawn by the program for every query.

**Greedy rule (condition `greedy`)**; example `greedy|14|0`

```text
You are one member of a team. Each member takes one of three roles: A, B or C.
Your role right now is: C
You work directly with six teammates. Their roles right now are:
First: A
Second: C
Third: B
Fourth: B
Fifth: B
Sixth: A
Rule: each teammate who has the same role as you counts as one conflict. Choose the role that gives you the fewest conflicts.
Now choose your role.
No need to explain. On the last line write only "Answer:" followed by A, B or C, nothing else.
```

**Heat bath with the random number in the prompt (conditions `T0.4`, `T0.7`)**; example `T0.4|14|0`

```text
You are one member of a team. Each member takes one of three roles: A, B or C.
Your role right now is: C
You work directly with six teammates. Their roles right now are:
First: B
Second: A
Third: B
Fourth: C
Fifth: A
Sixth: A
Rule: each teammate who has the same role as you counts as one conflict.
The team works at temperature T = 0.4. Choose each role X with probability proportional to exp(-n_X / T), where n_X is the number of your six teammates who have role X.
Here is a random number drawn uniformly from [0, 1): 0.3229. Use it to make the choice: go through the roles in the order A, B, C and take the first one whose cumulative probability exceeds the random number.
Now choose your role.
No need to explain. On the last line write only "Answer:" followed by A, B or C, nothing else.
```

**Heat bath only at conflicts (condition `Tc0.5`)**; example `Tc0.5|14|0`

```text
You are one member of a team. Each member takes one of three roles: A, B or C.
Your role right now is: B
You work directly with six teammates. Their roles right now are:
First: C
Second: C
Third: A
Fourth: A
Fifth: A
Sixth: B
Rule: each teammate who has the same role as you counts as one conflict.
If none of your six teammates has your current role, you have no conflict: keep that role and do not use the random number below.
Otherwise, choose each role X (your current role included) with probability proportional to exp(-n_X / T) with T = 0.5, where n_X is the number of your six teammates who have role X.
Here is a random number drawn uniformly from [0, 1): 0.8830. Use it only if you have at least one conflict: go through the roles in the order A, B, C and take the first one whose cumulative probability exceeds the random number.
Now choose your role.
No need to explain. On the last line write only "Answer:" followed by A, B or C, nothing else.
```

## 3. Counterflow in three lanes

In every query of the collective runs the program draws the names of the three lanes (six assignments of A, B, C) and the order in which the lanes are listed (six orders), 36 combinations. The cells of a lane are always listed from offset +2 to -2. The list of moves, the tool sentence and the last sentence name only the moves open to the bird (two for an outer lane, three for the middle lane).

### 3.1 With the die

Example: a bird in an outer lane meets one other bird one cell apart, nothing else in view; lanes named A, B, C in order.

```text
You are a bird on a track of square cells with three lanes, A, B and C, that run side by side: lane B lies between lane A and lane C. A cell holds at most one bird.
Cells are named by lane and by offset along the track from your own cell, which is A 0. Offset +1 is the next cell on the side you are facing, offset -1 is the next cell on the opposite side, and so on.
A bird can stay where it is or move one cell toward the side it faces, ending in its own lane or in a lane next to its own. Your moves are named by the lane they end in:
A: to A +1
B: to B +1
The wind you feel right now blows toward the + side.
A bird faces the way the wind it feels blows. Each bird sees only the cells around itself and chooses its own move.
You can see the cells with offsets from -2 to +2 in all three lanes. Right now:
A +2: a bird facing the - side
A +1: empty
A -1: empty
A -2: empty
B +2: empty
B +1: empty
B 0: empty
B -1: empty
B -2: empty
C +2: empty
C +1: empty
C 0: empty
C -1: empty
C -2: empty
A move into a cell that is occupied does not happen. If two birds try to move into the same cell, neither of them moves. If the moves of two birds would cross each other, neither of them moves.
Rule: a move that does not happen counts as one clash for the bird that tried it. The birds' shared goal is that every bird travels as smoothly as it can along the wind it feels, with as few clashes as possible.
A tool named draw is available: give it a weight for any of A, B and Stay (an option you leave out gets weight 0), and it returns one of them drawn at random with probability proportional to the weights. You may use it or not.
Now choose your move.
No need to explain. End your final reply with a line that contains only "Answer:" followed by A, B or Stay.
```

**Tool offered with this prompt** (the options are the moves open to this bird, in the order of the prompt, then `Stay`)

- name: `draw`
- description: "Draws one of the options A, B, Stay at random. The probability of each option is its weight divided by the sum of all the weights, so a larger weight makes that option more likely. An option whose weight is left out or is 0 is never drawn. Weights must be non-negative and at least one must be positive. Returns the option drawn."
- parameters (JSON schema):

```json
{
  "type": "object",
  "properties": {
    "weight_A": {
      "type": "number",
      "minimum": 0,
      "description": "Weight for A"
    },
    "weight_B": {
      "type": "number",
      "minimum": 0,
      "description": "Weight for B"
    },
    "weight_Stay": {
      "type": "number",
      "minimum": 0,
      "description": "Weight for Stay"
    }
  },
  "required": [],
  "additionalProperties": false
}
```

- reply to the model: `Option drawn: X`, or `Error: give non-negative numbers, at least one of them positive. Nothing was drawn.`

### 3.4 Repeated queries
